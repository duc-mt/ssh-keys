# Security Policy

## Supported Versions

Currently, this repository does not have strict versioning. We recommend always pulling from the `master` branch.

| Version | Supported          |
| ------- | ------------------ |
| master  | :white_check_mark: |

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities. Instead, please reach out to the author directly via their GitHub profile or known contact information.

If you find a flaw in the backup/restore scripts (`backup.sh` or `restore.sh`), or an issue with how OpenSSL encryption/permissions are handled, please provide a detailed description and steps to reproduce. We will review and address it promptly.
